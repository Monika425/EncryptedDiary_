# Image credits and UI notes

The interface uses remote Unsplash image URLs for decorative backgrounds. Images are loaded from Unsplash and require an internet connection. See the Unsplash License: https://unsplash.com/license

The five diary-card wallpapers are selected in the browser on each page load. The selected image is intentionally not persisted, and this visual change does not add or alter database columns, routes, or stored diary data.
